# Transformer-Based LLM from Scratch
 
A small GPT-style language model built from scratch in Python to understand how modern Large Language Models (LLMs) work, end to end. The goal is learning: every part of the transformer is written and explained step by step, from raw text to generated output.
 
> **Status: Ongoing.** This repository is updated as the project grows.
 
## About
 
Large Language Models look complicated from the outside, but they are built from a small set of ideas. This project rebuilds those ideas in a small, readable form:
 
- how text is turned into tokens
- how tokens become embeddings with position information
- how self-attention lets the model look at earlier words
- how a transformer block is stacked and trained
- how the trained model generates new text
